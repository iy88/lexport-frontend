# 需求文档

## 1. 应用概述

### 1.1 应用名称
律航出海·法律AI智能体

### 1.2 应用描述
律航出海是由高校法学专业团队打造的法律AI智能体，聚焦非洲制造业出海企业的合规痛点，通过整合权威法律数据库、AI技术与本地合规资源，提供低成本、可追踪、嵌入式的合规支持服务。

## 2. 用户与使用场景

### 2.1 目标用户
- 计划或已在非洲开展制造业务的中国企业
- 需要了解非洲制造业合规要求的企业决策者
- 寻找非洲本地合规服务机构的企业

### 2.2 核心使用场景
- 企业出海前期：查询目的国法规要求，使用合规初诊工具评估合规风险
- 企业运营期间：追踪法规更新动态，获取合规资讯
- 寻求专业服务：筛选匹配本地合规服务机构

## 3. 页面结构与功能说明

### 3.1 页面结构

```
律航出海网站（单页面应用）
├── 导航栏（固定顶部）
├── 首屏 Hero 区
├── 法规库模块
├── 资讯库模块
├── 机构推荐模块
├── 关于我们模块
├── 底部版权栏
└── 登录/注册页面
```

### 3.2 导航栏

**功能说明**
- 固定在页面顶部，支持锚点跳转至各模块
- 导航项：首页、法规库、资讯库、机构推荐、关于我们、登录
- 点击导航项平滑滚动至对应模块
- 点击「登录」跳转至登录页面

### 3.3 首屏 Hero 区

**功能说明**
- 展示平台核心信息与价值主张
- 内容包含：
  - 主标题：律航出海·法律AI智能体
  - 副标题：非洲制造业法律数据整合 + 合规机构智能筛选匹配
  - 平台简介：依托高校法学专业资源，融合AI技术与权威法律数据库，为出海企业提供低成本、可追踪、嵌入式全流程合规支持，高效打通非洲出海合规「最后一公里」。
  - 两个行动按钮：
    - 「立即体验合规初诊」：点击后跳转至法规库模块的合规初诊工具
    - 「了解我们的服务」：点击后跳转至关于我们模块

### 3.4 法规库模块

**3.4.1 模块标题与说明**
- 模块标题：非洲制造业合规法规库
- 模块说明：聚焦非洲重点制造业国家，提供结构化、可检索、带场景标注的法律原文，帮你快速定位合规要点，避免踩坑。

**3.4.2 核心功能**

**功能1：人工标注+法规整合**
- 展示基于非洲本地权威数据库收录的制造业高频法规与判例
- 每条法规包含以下标注信息：
  - 适用场景
  - 效力层级
  - 处罚条款
  - 生效/修订时间
- 支持查看法规原文

**功能2：制造业高频场景分类**
- 提供七大场景分类标签：海关进出口、劳工雇佣、数据安全、环保合规、税务、产品认证、知识产权
- 用户可按场景标签筛选法规
- 展示符合筛选条件的法规列表

**功能3：合规初诊工具**
- 提供可交互表单，用户输入以下信息：
  - 目的国（下拉选择）
  - 企业规模（下拉选择）
  - 业务场景（多选，对应七大场景分类）
  - 预算区间（下拉选择）
- 用户提交表单后，系统自动匹配法规要点
- 生成定制化合规初诊报告，报告内容包含：
  - 匹配的法规要点
  - 法规原文链接
  - 高风险提示
- 支持下载或查看报告

### 3.5 资讯库模块

**3.5.1 模块标题与说明**
- 模块标题：非洲合规动态资讯库
- 模块说明：实时更新中非合作政策、法规修订动态与行业合规热点，让你随时掌握出海环境变化。

**3.5.2 核心功能**

**功能1：中非合作新闻**
- 展示收录的中非合作论坛、中国驻非使馆公告、主流财经媒体发布的制造业投资政策与合作动态
- 支持按国家、行业、政策类型分类筛选
- 每条新闻包含标题、摘要、发布时间、来源
- 点击新闻可查看详细内容

**功能2：合规热点追踪**
- 展示基于行业热议度识别的热点事件
- 每条热点包含：
  - 事件背景
  - 涉事法规
  - 企业应对案例
  - 「热点合规风险提示」
- 点击热点可查看详细内容

**功能3：法规更新动态**
- 展示非洲各国法规修订信息（修订/新增/废止）
- 每条更新动态包含：
  - 国家
  - 法规名称
  - 更新类型（修订/新增/废止）
  - 更新内容摘要
  - 更新时间
- 点击动态可查看详细内容

### 3.6 机构推荐模块

**3.6.1 模块标题与说明**
- 模块标题：非洲本地合规机构推荐
- 模块说明：联合非洲本地商会与行业协会，为你推荐经过筛选的合规服务机构，覆盖制造业全场景需求。

**3.6.2 核心功能**

**功能1：商会背书的本地机构名单**
- 展示经非洲本地商会、行业协会推荐的律师事务所、合规咨询公司、会计师事务所等机构
- 每个机构展示核心信息：
  - 机构名称
  - 机构类型
  - 所在国家
  - 推荐商会/协会

**功能2：按制造业场景精准分类**
- 提供场景标签分类：劳工合规、税务咨询、海关报关、知识产权、环保认证等
- 支持按目的国、服务场景、预算区间筛选机构
- 展示符合筛选条件的机构列表

**功能3：透明化信息呈现**
- 每个机构附详细信息：
  - 机构简介
  - 服务范围
  - 典型案例
  - 联系方式入口（点击后显示联系方式或跳转至外部链接）

  - 使命：让中小制造企业在非洲出海路上，合规不再成为门槛，让每一步都走得更稳、更安心。

## 4. 业务规则与逻辑

### 4.1 合规初诊工具逻辑
- 用户提交表单后，系统根据用户输入的目的国、企业规模、业务场景、预算区间，自动匹配法规库中的相关法规
- 匹配规则：
  - 目的国：精确匹配
  - 业务场景：匹配用户选择的场景标签
  - 企业规模与预算区间：作为辅助筛选条件
- 生成报告时，优先展示高风险法规，附法规原文链接

### 4.2 资讯库更新逻辑
- 中非合作新闻、合规热点追踪、法规更新动态由后端定期更新
- 用户访问资讯库时，展示最新内容

### 4.3 机构推荐筛选逻辑
- 用户选择筛选条件后，系统根据目的国、服务场景、预算区间匹配机构
- 匹配规则：
  - 目的国：精确匹配
  - 服务场景：匹配机构的服务范围标签
  - 预算区间：匹配机构的服务价格区间

### 4.4 登录/注册逻辑
- 注册时，系统验证用户名唯一性、密码强度、邮箱格式
- 登录时，系统验证用户名与密码匹配
- 登录成功后，用户可访问需要登录权限的功能（如保存合规初诊报告）

## 5. 异常与边界情况

| 场景 | 异常情况 | 处理方式 |
|------|----------|----------|
| 合规初诊工具 | 用户未填写必填项 | 提示用户补全信息 |
| 合规初诊工具 | 系统无法匹配到相关法规 | 提示「暂无匹配结果，请调整筛选条件」 |
| 资讯库 | 暂无资讯内容 | 提示「暂无资讯，敬请期待」 |
| 机构推荐 | 筛选条件无匹配机构 | 提示「暂无匹配机构，请调整筛选条件」 |
| 登录 | 用户名或密码错误 | 提示「用户名或密码错误，请重试」 |
| 注册 | 用户名已存在 | 提示「用户名已被注册，请更换」 |
| 注册 | 密码强度不足 | 提示「密码需包含字母、数字，长度不少于8位」 |
| 注册 | 邮箱格式错误 | 提示「请输入正确的邮箱格式」 |

## 6. 验收标准

1. 用户访问网站首页，查看首屏 Hero 区的平台介绍
2. 用户点击「立即体验合规初诊」按钮，跳转至法规库模块的合规初诊工具
3. 用户填写目的国、企业规模、业务场景、预算区间，提交表单
4. 系统生成定制化合规初诊报告，用户查看报告内容（包含法规要点、法规原文链接、高风险提示）
5. 用户通过导航栏跳转至机构推荐模块，按目的国、服务场景筛选机构
6. 用户查看符合条件的机构列表，点击某个机构查看详细信息（简介、服务范围、典型案例、联系方式）
